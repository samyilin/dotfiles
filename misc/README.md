# What is this?

Code to install must-have / optional programs for different systems
(Linux distros,WSL or Mac).

I will eventually turn some of them into specific purpose Dockerfiles.

## What would be in here?

Programs that are not present in a minimal install.

Every distro setup (`ubuntu/`, `fedora/`, `arch/`) installs git,
tmux, vim and neovim, plus whatever system tools that distro is
missing. Emacs and busybox are added where the distro packages them
(`fedora/`, `arch/`).

This entire folder/sub-project is NOT READY FOR PRODUCTION USE. Use with
caution.
